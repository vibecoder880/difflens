## 5. Not fixed — needs decision

- **N1 (cosmetic)** `core/src/heuristic/deltas.rs:291-297` — `fmt_f64` casts
  `v.round() as i64`; amounts ≥ 2^63 saturate to `9223372036854775807` in the
  human-readable flag *detail* string (e.g. the 27-digit probe). The f64 delta
  used for severity is correct. No real-world VND amount reaches 9.2e18 (VN
  GDP ≈ 1e16 ₫/yr). Decide: branch to plain `{v}` formatting for |v| ≥ 2^63,
  or accept as out-of-domain.
- **N2 (perf, advisory)** align stage = 7.5 s release at 10 k blocks
  (O(n·max_chunk), chunk=2000, memory-bounded by design — documented in
  `needleman.rs`). Linear in n beyond chunk size; fine for release builds, but
  the sweep test's 120 s assert is debug-budgeted at 105 s and could flake on
  a slower machine if these tests are ever committed to CI. Recommend
  time-gating on `cfg(debug_assertions)` or raising the bound if committed.
- **N3 (observation)** Store's rusqlite `Connection` is `Send` but not `Sync`;
  sharing one `Store` across threads is impossible without an outer `Mutex`.
  Concurrent access works via multiple connections on one file (WAL +
  busy_timeout, verified). If the Tauri shell ever wants a shared handle,
  wrap in `Arc<Mutex<Store>>` there — no change needed in core.
